Instruções da aula

1- Criar pasta localmente

2- Nomear a pasta como exercicio-node-nome

3- Criar package.json (terminal -> npm init -y)

4- Editar "description" e "author"

5- Fazer commit inicial e criar repositório github PÚBLICO

6- Criar package-lock.json (terminal -> npm install)

7- Fazer commit com a alteração realizada

8- Criar README pela interface do navegador no Github

9- Sincronizar a criação do README no VSC (comando git pull origin main)

10- Terminal -> npm install express

11- Criar arquivo ".gitignore"

12- Inserir "node_modules" na primeira linha

13- Atualizar o README com a intrução de como instalar o express

14- Criar commit com as atualizações recentes

15- CONFERIR SE NÃO ESTÁ SUBINDO O NODE_MODULES

16- Criar o arquivo app.js

17- Atualizar package.json:
    17.1- "main": "app.js"
    17.2- "type": "module"
